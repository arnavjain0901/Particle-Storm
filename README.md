# 🌌 PARTICLE STORM

### ✨ Where hand gestures meet a universe of particles.

**Particle Storm** is an interactive 3D particle experience that transforms real-time hand movements into dynamic visual effects. Built with Three.js and MediaPipe Hands, it lets you control a digital particle universe using nothing but your hands.

💜 **Customize. Interact. Create your own storm.**

---

## 🚀 Features

🖐️ **Real-Time Hand Tracking**
Control the particle system through live webcam hand gestures.

🌌 **Dynamic 3D Particle System**
Explore a responsive particle environment with fluid, animated visual effects.

💥 **Gesture-Driven Effects**

* ✋ Open palm — expand the particle system.
* ✊ Fist — compress the particles.
* ☝️ Pointing gesture — focus particles around a point.
* ✌️ Peace sign — create a vortex effect.

🎨 **Customizable Visuals**

* Multiple color presets and a custom color picker.
* Adjustable particle size.
* Customizable glow intensity.

🎛️ **Interactive Storm Control Panel**

* Switch between manual effects and gesture mode.
* Customize the appearance of the particle system.
* Reset settings whenever you want.

⚡ **One-Click Launch**
Use the included `start.bat` file to launch the experience through a local server.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/arnavjain0901/Particle-Storm.git
```

### 2. Open the project folder

```bash
cd Particle-Storm
```

### 3. Launch the application

On Windows, double-click:

`start.bat`

Alternatively, start a local server manually:

```bash
py -m http.server 8000
```

Open this address in your browser:

`http://127.0.0.1:8000/particle_storm.html`

### 4. Allow webcam access

Grant camera permission when prompted. Make sure your webcam is connected and that your browser can access it.
